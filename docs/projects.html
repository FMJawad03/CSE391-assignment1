PROJECT 02

Foundora - A Platform Connecting Startups and Investors

A university course project developed to connect startups with potential investors through separate authentication systems for each user type. Foundora provides a dedicated space for startups and investors to interact and explore potential funding opportunities. Built using HTML, CSS, PHP, JavaScript and MySQL, the project demonstrates full-stack web development, database integration and user authentication.

PROJECT 03

Dorm Door - A Platform for Student Accommodation Management

A university course project developed to simplify student accommodation management through a centralized web platform. DormDoor allows students to browse dormitories, apply for rooms, and track applications, while dorm administrators manage listings and availability. A super administrator oversees users, applications, payments, and other system operations. Built using the MERN stack, the project demonstrates full-stack development, database integration, and role-based access control.
